# Girl Peps — Web Platform & WhatsApp Order System

Plataforma e-commerce y catálogo digital premium para **Girl Peps** (*Beauty & Science*), especializada en péptidos y compuestos de investigación (*Research Use Only - RUO*).

## 🌸 Características Principales

- **Identidad Visual Cream Luxury**: Paleta cálida basada en Crema Principal (`#FBF3E4`), Crema Claro (`#FFF9F0`), Dorado Champagne (`#C6A15B`) y Marrón Oscuro (`#3B302A`).
- **Integración Directa con WhatsApp (+1 862 233-3919)**: Generación automática de comandas de pedido formateadas para WhatsApp (`wa.me/18622333919`).
- **Detección de Cupones vía URL (`?coupon=NOMBREPEPS`)**: Asignación automática de cupones y vendedores referidos al acceder mediante enlaces promocionales.
- **Catálogo Interactivo con 33 Productos**: Buscador en tiempo real, filtro de disponibilidad (*In Stock*, *Sold Out*, *In Transit*) y categorías.
- **Módulo de Carrito & Cupones**: Aplicación de cupones (ej. `NOMBREPEPS`) con descuento automático de -$10.00 USD.
- **Secciones Informativas & Educativas**: "¿Qué son los péptidos?", "Cómo Comprar" (4 pasos) y "Garantía de Confianza".

## 🚀 Tecnologías

- **Core**: React 18, TypeScript, Vite
- **Estilos**: Tailwind CSS, Google Fonts (*Playfair Display*, *Montserrat*, *Poppins*)
- **Iconos**: Lucide React

## 📦 Instalación y Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/FranAC18/girlpeps.git
cd girlpeps

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```
